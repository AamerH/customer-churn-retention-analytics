# customer-churn-retention-analytics
Customer churn analysis using SQL, Python, and Tableau to identify high-risk customer segments and revenue exposure.

# Customer Churn & Retention Analytics

## Overview

Analyzed 7,043 telecom customer records to identify customer segments with elevated churn risk and quantify the monthly charges associated with churned customers.

## Tools

- SQL
- Python / Pandas
- Tableau
- Google Sheets

## Key Findings

- Overall customer churn rate: 26.54%
- Month-to-month customers: 42.71% churn
- Customers with 0–12 months tenure: 47.44% churn
- Fiber-optic customers: 41.89% churn
- Monthly charges associated with churned customers: $139,130.85

## Business Recommendations

- Prioritize retention offers for new customers.
- Encourage month-to-month customers to transition to longer-term contracts.
- Investigate the elevated churn among fiber-optic customers.
- Use customer segmentation to target retention campaigns.
